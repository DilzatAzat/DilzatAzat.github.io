# Code Review

Read requirements and acceptance criteria, then inspect the complete diff and relevant surrounding code. Report actionable findings only, ordered by severity, covering correctness, regressions, unmet criteria, edge cases, security, data integrity, architecture consistency, and missing or misleading tests. Each finding should include severity, file/symbol, concrete problem, impact, reproduction when possible, and correction. Ignore pure style preferences.
